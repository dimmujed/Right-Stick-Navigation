Right Stick Navigation


This is a Decky plugin for Steam Deck that enables the right stick to be used to navigate Big Picture Mode aka the full screen Steam UI and submenus. It will not interfere with games.


It installs pre-enabled, but there is an option to disable it in the Quick Access Menu.


I recommend hiding it by opening the Quick Access Menu, selecting the Plug Icon for Decky, then the gear icon -> Plugins -> scroll until you find Right Stick Navigation and select the "..." button then select "Quick access: Hide".


I have wanted this as a quality of life / accessibility feature since the launch of the Steam Deck, and have seen others request or yearn for the likes. This was inspired by the Nintendo Switch, which launched with this feature. I find it especially valuable as someone that often lays on their right side in bed with the Steam Deck's weight pressing into my right hand.
